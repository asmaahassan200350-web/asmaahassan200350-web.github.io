About Me

I'm a Software Testing Engineer with practical experience in software quality control across web and mobile applications. My work includes reviewing requirements, designing and executing test cases, performing functional, exploratory, regression, and API testing, and documenting defects clearly for investigation and resolution.

During the Fawry hands-on training program, I applied STLC practices, tested REST APIs with Postman, analyzed logs and microservice workflows, and developed basic automation scripts using the Page Object Model and data-driven testing. In professional roles at Rockai Dev and Pulvent, I tested healthcare, legal-learning, educational, and business web platforms, with attention to role-based access, integrations, financial workflows, and cross-platform behavior.

I continue to strengthen my automation skills with Java, Selenium WebDriver, TestNG, Maven, and Appium, while using AI as a supporting tool—not a replacement for independent validation and critical thinking.
